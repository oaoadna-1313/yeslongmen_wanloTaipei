# [閱思龍門] 網羅臺北——數位媒體識讀 教學平台

本專案依據「學思軒・閱思龍門」系列課程規範與「閱思龍門網頁標題格式技能」（`yuesilongmen-web-title-spec`）研發製作，針對國中八年級國語文素養、資訊科技與跨領域探究課程，打造「**臺北主題數位文本品質與正確性評鑑**」互動教學平台。

---

## 專案內容清單

1. **互動教學網頁**：[`index.html`](file:///c:/2026_網羅臺北/index.html)
   - 整合迷思破冰 3 題挑戰、出處光譜互動圖鑑、五星評鑑雷達圖（Chart.js 互動繪製）、大稻埕老屋對照擂台（抓漏放大鏡線索高亮與專家診斷）、進階搜尋密技工具箱、線上實作探究任務單、一鍵產出成果報告與列印排版支援。
2. **教材出處與品質辨識資料庫**：[`DIGITAL_TEXTS_DATABASE.md`](file:///c:/2026_網羅臺北/DIGITAL_TEXTS_DATABASE.md)
   - 彙整臺北主題（大稻埕老屋活化、大巨蛋公共安全等）橫跨政府官方、協作百科、深度調查新聞、社群部落格至內容農場之完整特徵、品質與盲點深度剖析。
3. **教學流程與教案設計**：[`TEACHING_PLAN.md`](file:///c:/2026_網羅臺北/TEACHING_PLAN.md)
   - 規劃 2 節課（90 分鐘）素養導向教學流程（迷思破冰 10min ➔ 出處掃描 15min ➔ 評鑑雷達 20min ➔ 擂台實戰 20min ➔ 自主網羅 20min ➔ 成果匯出 5min）。
4. **品牌徽章資源**：

## 核心亮點與特色

- **嚴格遵循品牌規格**：頂部 Sticky Header 與底部 Footer 完整落實「閱思龍門網頁標題格式技能」標準架構。
- **動態互動雷達**：採用 Chart.js 動態繪製五星指標（權威歸屬、佐證查核、立場動機、時效歷程、格式避雷），點選即可視覺化切換不同出處的雷達輪廓。
- **抓漏放大鏡實戰**：點擊放大鏡即可於案例擂台文章中高亮顯示「農場聳動誘餌標題」與「具名平衡報導證據」，直接提升學生對虛假訊息的警覺。
- **探究成果一鍵匯出**：學生線上填寫評鑑分數與思辨心得後，可一鍵生成格式整齊的成果報告文字，或純淨直接列印為實體學習單。
